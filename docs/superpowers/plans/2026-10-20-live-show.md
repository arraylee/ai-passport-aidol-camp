# Aidol Live Show Implementation Plan

> For agentic workers: implement natively with executing-plans; review changes independently before release. User authorized direct execution; no Git commit or push.

**Goal:** Six-device offline name cards, mutual friends, gallery and reliable proximity/PTT demo.
**Architecture:** Extend standalone ESP-IDF application; pure state modules for deterministic tests, existing BSP/ESP-NOW, Flash-resident profile artwork, LVGL pages.
**Tech Stack:** ESP-IDF 5.5.3 / ESP32-C3 / LVGL 9 / pure C host UBSan / Python asset and release tooling.
**Spec:** docs/superpowers/specs/2026-10-20-live-show-design.md

## Global Constraints
Six IDs and names unchanged; SN 0x356000..0x359fff untouched; preserve id/volume compatibility. No cloud writes, no router, no whole-chip erase, no commits/push. PTT only long UP, release stops. Bluetooth clicker separate and out of this build.

## Review Focus
- Asynchronous RX/capture newer than cached main time must not be discarded; genuinely stale frames must be dropped.
- Press/hold/release crossing pages must not open microphone or select another person.
- All medium/far people equal size; disappearing/reappearing nearest person cannot cause false bearing.
- Friend late packets, unilateral confirmation, restart and save failure cannot show false success.
- Full names/signatures and avatars within 240x320 and 48KB LVGL pool; physical six-device acceptance remains separate.
