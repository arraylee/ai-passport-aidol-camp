# AIdol live firmware v0.4.0 design

User-approved scope: preserve working v0.3.3 audio implementation; ignore external walkie-talkie repository. Add a visible room-joining experience, friend-add animation plus persisted avatar/name/signature, home album editable by the existing miniapp, and boot/deep-wake animation following existing AIdol firmware. Ten minutes idle before sleep; six-hour battery life is a measurement target, never an unmeasured guarantee. User specifies long DOWN returns from Add Friend to HOME; physical key mapping is being recorded.

Builder choices: keep one local "直播房间", no account/room code/router. Radio tile opens a lobby; center joins, real HELLO membership drives visible teammate arrivals, center proceeds to radio after join. Long DOWN exits radio to lobby, then leaves room to HOME. Display online vs joined separately. Only joined targets receive/play speech; coordinator1 must have joined. No fabricated joins/counts. Wire membership flag16; new features require all devices v0.4.0. Speech codec/timing/priority6 and five-ms yield remain.

Three home tiles: 加好友 / 对讲机 / 相册, existing left portrait/right profile stays. Friend page offers nearby candidate + confirm and an explicit saved-friends entry after completion; long DOWN always returns. Only complete mutual confirmation + persisted card transfer may show the completion animation. Animation: small moving card/dots/check, no full-screen scale/opacity layers. Saved friend list has avatar, name and signature preview; center shows complete saved card, usable offline/reboot. Re-adding refreshes the snapshot. Identity remains demo device ID+validated MAC/session, not cloud social friendship.

Friend storage at0x3b0000 size0x30000 subtype0x42: six slots, each two16KiB banks. Bank contains version/owner/local-session metadata, UTF8 name49/intro85, canonical64x104 RGB565 avatar13312B, thumbnail32x32 2048B, CRC commit header written last. Keep previous valid bank on failure. No avatar means neutral placeholder. Local portrait sampled from mapped96x156 descriptor. Reliable pull protocol uses kinds7 META,8 REQUEST,9 DATA (200-byte frame for META/DATA,36 for REQUEST), target ID, boot, monotonic seq, both social sessions, snapshot CRC token and byte offset. Main thread owns state; transmit only idle audio, abort stale peer/session/phone upload. Retry missing chunks; never mark saved until checksum/flash complete. Budget no full avatar heap allocation; small buffers + mapped Flash.

Album storage at0x400000 size0xc0000 subtype0x43: two256KiB RGB565 banks plus256KiB upload scratch. Existing miniapp config img_mode:'fullscreen', same type2 BEGIN/DATA/END framed upload as avatar. Support its baseline JPEG up to240x320 via existing Espressif esp_new_jpeg1.0.2 block decoder; fixed temporary stripe <=7680B, stream output into inactive flash bank. Header/CRC committed last; interrupted/corrupt uploads preserve old photo and own avatar. Gallery shows supplied image at native resolution, centered, with long DOWN returning home. Empty gallery offers clearly marked QR demonstration; no pretend actual WeChat identity. Standard miniapp uploads replace this with real QR photo. Avatar PNG path preserved. Config mode must not be confused with saved name/avatar payload.

Power: user requests the previous AIdol logic. Verified source uses deep sleep, closes audio/radio/display, GPIO0 wake, suppresses waking key until release, restores saved profile before first visible home frame; use10min threshold600000ms. No network receiving during deep sleep; wake reboots and offers rejoin. Audio, user keys, active profile upload and ongoing card transfer prevent sleep; mere discovery heartbeats do not reset timer. Boot/wake use the original first-frame/backlight transition as reference, no screenshot flash or binding screen on wake. Battery percentage from CW2017 if valid; exact six-hour life requires discharge/current evidence.

Safety: ESP32-C3 8MB noPSRAM; preserve cardid356000..359fff, originalNVS9000..efff, demo_cfg360000/6000, profile_store380000/30000 and recovery700000/100000. No full erase, no writes before exact MAC validation. Add partitions only in unused gaps; safe flash still3 segments. Live installed v033 retained in releases/v0.3.3.
