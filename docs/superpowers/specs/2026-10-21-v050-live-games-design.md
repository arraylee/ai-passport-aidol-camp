# v0.5.0 直播交互与唱跳挑战

按现有三键硬件、ESP-IDF5.5.3和240×320 LVGL实现。用户要求直接完善现有demo，沿用上/中选择、下确认；长下保留紧急回首页，但相册先显示确认返回。

1. 首页选组队后立刻播放1.8秒加入动画，完成即进入Aidol直播房间，每次返回首页重进都重播。名单只显示名字、远近/信号，信号条底边对齐，左低右高。列表末尾玩游戏、返回；无队友仍可玩游戏/返回，不能发言。对队友或全体短下仍进入音量。
2. 取消碰一碰后，用近期原始信号已离开贴近区并持续600毫秒解除防重复标记，再满足原1.8秒/双向/唯一最强条件可重弹。相互确认及CRC完整名片保存继续保持，未激活仍禁用。
3. 对讲默认播放90%，用新版迁移标记仅初始化一次，之后保留用户调节。安装重置配置也改90%。
4. 好友列表最后一行返回；详情固定可见下键返回首页。相册任意键先弹返回按钮，短下确认，上/中（含长按）取消按钮，不泄漏同一次输入。
5. 游戏菜单：开始游戏、排行榜、返回。用户选择声控小鸡参考，20秒音高跳跃、障碍物和金币，右上角分数，碰撞不停局，右上角分数。开场3秒准备并自动取舒适音高；有声基频越高跳越高，无声回地面；不用大声喊。每局最优分通过demo_cfg原子NVS记录，重启可读；低分不覆盖高分。
6. 游戏菜单/游玩/结算/排行榜均停用本机对讲收发，仍在房间发HELLO和成绩；协调器1继续仲裁其他人的对讲。游戏中HELLO标志告知队友，其他人不可私讲给忙碌者；全体广播只由可收听者播放。
7. 排行榜只显示当前同房间、在线且有有效成绩者，包括本人；按最高分降序，同分同名次，用编号稳定排序；无人有记录显示空态。成绩包绑定MAC/boot、当次room_session和游戏版本，离房/离线/重启不残留旧会话成绩。新成员周期广播自己的持久最高分。

预算：游戏状态/排行榜数百字节，麦克风窗口静态640×int16_t，低采样整数YIN风格差分/归一化求基频，沿用现有采集任务但游戏独占用途；不新增永久任务或大图层。UI复用现有对象，位置变化，游戏25fps其他10fps。参考公开YIN论文 https://www.ee.columbia.edu/~dpwe/papers/deChevK02-yin.pdf；参考笔记 https://www.xiaohongshu.com/explore/66f9bb05000000001b02059d ，不存储分享凭据。

实施顺序：交互/重试测试与修复；游戏/音高/积分/会话广播模块及测试；UI真实240×320渲染、字体检查；完整宿主/IDF容量/独立源码重建/发布校验；设备接入后按已授权流程保护SN刷写、测麦克风音高/流畅度/多机排行，未实测项明确标记。
