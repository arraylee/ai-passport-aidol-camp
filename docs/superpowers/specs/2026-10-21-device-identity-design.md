# v0.6.0: physical identity independent of demo role

User approved replacing role-based identity and delivering a new official-web-flashable BIN; no connected-device writes authorized this turn. Six hardware devices may all choose the same profile role and must still discover, mutually confirm friendship, share private/broadcast half-duplex audio and exchange room scores. Existing near-contact, activation, UI controls, microphone/game behavior stay.

Implementation choice: authoritative ESP-NOW source MAC identifies hardware. Preserve original SN in cardid for miniapp; do not broadcast secrets or claim cloned DeviceKey detection. HSW2 carries destination and speaker MAC references (212B maximum). An identity adapter assigns each MAC a receiver-local slot, leaving core.id as the self/profile role; all target references are translated before existing core/profile/card handlers. No role-only over-air routing. HSW1 is isolated; all participants require v0.6.0.

Persist local slot/MAC roster and friend mask together in one versioned CRC NVS blob. Saved friends reserve their slots. Unknown hardware can reclaim an offline nonfriend slot only while no active PTT/friend transaction; never evict a saved friend silently. Capacity remains five other hardware identities; reset demo data to start a different full roster. Header HFC2 binds snapshot to owner and peer MAC. Ignore old role-only friendships once on upgrade; preserve own profile, SN and gallery. New friendships survive reboot and discovery-order changes. NVS commit must precede friendship persistence.

Elect room coordinator by lowest MAC among online room members, retaining arbitration while gaming. On coordinator change clear floor, invalidate old epochs/queued voice and require release/repress of held PTT; allow old lease to expire before new grants. No required Miao/role1 device. Production diagnostics report role separately from physical identity/host, and capacity explicitly if needed.

Keep current partition CSV exactly. Free the unused 204x204 legacy profile.gallery bitmap (~83KB) to fund protocol/storage code; real gallery and friend QR are separate. Update desktop helper to v0.6.0 support and permit repeated profile roles on new firmware, while retaining the legacy safeguard for old versions. Same profile settings remain compatible with miniapp 96x156 PNG uploads.

Verification: regression first reproduces same-role failure; MAC-encoded six-node simulation covers same roles, different discovery orders, private/broadcast voice, host departure/rejoin, stale/forged/reordered packets, mutual touch, scores and roster persistence. Snapshot fake-flash tests cover UID binding and old-record rejection. Existing host/audio/UI tests and native screenshots, IDF build/size, independent source rebuild, web boundary/ZIP/hash checks. Physical six-device/radio/sleep/battery acceptance remains pending; do not attach or flash current hardware.
