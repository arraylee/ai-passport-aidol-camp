# v0.7.10 手动好友兜底

## 操作与边界

双方从首页打开「好友」，显示原好友列表，同时自动寻找。仅在双方主动打开好友时按信号选最近的人；其他首页上的胸卡不参与手动候选。双方互选稳定后进入已有头像预览/确认页，各按下键确认，沿用名片交换与好友详情流程。长下取消回首页，重新打开好友可直接重试，不需要等自动碰一碰的分离冷却。手动流程允许更新已有好友，避免单边重置后无法配对。

自动碰一碰继续仅在首页，以-30dBm/6dB领先/1800ms及双向意图判定。手动寻找使用-65dBm最低信号、3dB领先、600ms/3个新样本与300ms/2次双向意图；这是RSSI筛选，不能承诺厘米距离。接近并不自动保存好友，始终双方确认。离开好友页、取消、未激活、小程序连接或硬件不可用时撤销手动意图。成功后名片页保留短暂完成握手，按返回才退出。

休眠是深睡，唤醒重新执行初始化，RAM中的匹配/取消状态会重建，激活与已保存好友仍持久化。没有现有证据证明休眠永久关闭自动扫描。代码验证不能代替实体睡眠/唤醒测试。

## 实现与验证计划

复用HELLO预留bit128标记主动寻找，保留HSW2包长度与MAC寻址；双方必须升级以支持手动兜底。复用现有状态机、头像预览、名片交换，不增加任务/队列/图片缓冲。好友页显示寻找提示，配对页保留明显下键确认。

先用真实HSW2打包/路由的六节点测试复现旧版不支持好友页寻找；覆盖同角色不同MAC、旁边更强的首页设备、最近互选/歧义、单方进入、取消立即重试、单边旧好友、离页/蓝牙/未激活、握手确认与模拟重启。原生240×320检查好友页/确认页，字体全量检查，全套宿主和工具测试、ESP-IDF5.5.3构建/size、独立源码ZIP重建、Web BIN边界/哈希。新版实机需两台均升级验证；未经确认不宣称完成现场兜底或20分钟唤醒验收。

## 实机验收步骤（待测）

1. 两台都升级v0.7.10，激活并断开小程序/蓝牙配置助手；其他胸卡可保持首页。
2. 两人都从首页进入「好友」，应见「寻找中…」，原好友仍可浏览。靠近并停稳后双方显示对方头像/名字。
3. 只确认一边时不应保存；另一边下键确认后，两边完成并进入对方名片。
4. 弹窗时长下取消，直接重新打开好友；不必分开，应能再次寻找。
5. 清空一边好友后重试，应允许更新另一边已保存的资料。只一人打开好友时不应拉入首页旁观设备。
6. 六台开机，三组分别打开好友并成对靠近，确认不串人；信号近似无法区分时稍微拉开其他候选。
7. 无操作20分钟后上键唤醒，双方重新进入好友，重复寻找和确认；记录页面、触发耗时及任何失败提示。

宿主测试通过仅表明状态/协议模拟正确；射频环境和真实深睡唤醒未验证。
