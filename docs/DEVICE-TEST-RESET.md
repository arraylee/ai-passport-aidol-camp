# 本轮设备刷写约定

用户要求：每次刷机默认恢复新机测试状态，方便重新验证欢迎、激活和碰一碰。无需整机备份。

- 每次明确核对当前设备MAC，只写发布包的0x0、0x8000、0x10000三段。
- 写入后先完成固件回读和保护区比较，再单独重置demo_cfg（0x360000+0x6000）、profile_store（0x380000+0x30000）、friend_store（0x3b0000+0x30000）、gallery_store（0x400000+0xc0000）。
- 仅预置本台已分配的编号和100%音量；激活、欢迎与好友键为空。用官方NVS生成器制作新设置，不能复用旧配置。
- SN/cardid（0x356000+0x4000）、原NVS及其他硬件身份数据保留，禁止全片擦除。前后比对SN与原NVS。
- 首次启动播放欢迎并正常保存欢迎标记，停在待激活；按下键后激活保存。此前激活/欢迎历史不恢复。
- 按本次指定角色重新通过小程序协议下发昵称、签名及96×156头像，不恢复旧好友和相册；相册使用固件自带不可扫描示例图。
- 测试重新互加时两台都需清除旧好友关系，仅清掉一台不能通过双方近距意向检查。

本次胡彦斌使用MAC尾号38:cc、演示编号2，签名“做你想做的事，成为你想成为的人！”。头像为原微博图片按比例适配96×156，使用stored-DEFLATE PNG以减少设备解码内存。
