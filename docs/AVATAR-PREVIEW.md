# 碰一碰头像预览 v0.4.15

确认页双方按同样比例显示长方形头像；本人使用本机96×156头像，对方使用实时32×52缩略预览，显示为72×117。小程序上传协议和原头像尺寸不变。

两台都需升级到v0.4.15。进入贴近确认页后先预览，短按下键仍只表示本人同意；只有双方确认后，才交换并保存完整名片。退出、离线、重新启动、目标或会话变化都会撤销预览，未激活及小程序连接时不预览。不写好友分区，也不预填好友列表。对方更新头像后约2秒发起新预览，丢包重试可能延长时间。

无线消息10为预览请求，11为预览数据；36/200字节，沿用包CRC和核心MAC/boot/seq验证，再验证双方社交会话及目标。图像3328字节静态缓冲，完整CRC通过后才提供给界面。对讲、已进入正式名片交换时优先暂停预览传输。

验收：两台升级并激活，首次贴近，双方未确认时都出现对方头像；单方确认不保存好友；取消后列表不增加；再贴近双确认，完整名片出现；小程序更换头像后，新碰一碰预览跟随变化。仍需双机现场验证速度及观感。
