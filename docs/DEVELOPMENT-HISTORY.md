六台使用同一固件，无需路由器、账号或云端。角色编号可重复，通信按原硬件MAC识别；公开SN用于真实身份重复检测。ESP-NOW固定信道6，房间调度自动选举，无需指定喵喵／1号。原有小程序可修改96×156头像、昵称、签名及相册；这些资料断电保存。

本版「唱跳挑战」改成唱歌才前进的固定关卡：持续发声推进，音高控高，停声停步并自然下落；可以在木桩上换气。没有游玩倒计时，到终点旗才结算，右上计分。普通金币50分，四枚闪亮高音金币各100分，通关100分，全金币无失误900分。游戏暂停本机对讲收发，继续留在房间；返回房间恢复对讲。调度设备玩游戏时仍为其他成员调度发言。

首页 FoloToy 左侧为电池图标（无百分比）：CW2017实际SOC填充，40%以上浅色、20–39%黄色、低于20%红色；未知/长时间读不到为灰色带横线，实际0%为红色空框。v0.7.4 自动检查电量计：全0/全FF的80字节参数，或可识别的本程序中断写入，采用原Aidol配置的4.2V 520mAh参数逐字节补齐、回读校验、提交并唤醒；已有正常非空校准保留。缺失、读写失败会退避重试，暂时失败保留最近有效电量，30秒仍没有有效值显示未知。正常5秒读一次，异常1秒重试；连续3次坏SOC重新检查并重启计算，两次恢复至少隔30秒。初始化按每步最多一次5ms I2C操作执行，不新增任务，不延后20分钟休眠；运行时补齐不写设备Flash、SN或用户资料。首次补齐和SOC计算需要几秒；本轮已读取有效SOC99–100%；电量准确性和完整充放电曲线仍待实测。详见 docs/BATTERY-RECOVERY.md。

首页默认选中「组队」，短按下键直接播放入房动画；每次返回首页也选中组队，上键可选好友，中键可选相册。首页沿用Aidol深蓝配色、红色选框，完整长方形头像；昵称20px、签名16px左对齐，与头像留16px间距。底部「好友／组队／相册」。ESP32-C3、8MB、无PSRAM、三个实体键、ES8311、240×320，ESP-IDF5.5.3。

## 操作

首次完整启动播放原Aidol创造营欢迎语及动画，随后短按下键激活；仅首次激活，重启保持。未激活不触发碰一碰。每次启动/唤醒都有JOY动画，20分钟无操作播放告别动画后深睡；休眠离线，上键唤醒后需重新进入组队。物理断电无法播放退出动画。亮度80%，**六小时续航尚未实测**。

短按在松手后触发；长上/下约600ms、长中800ms。上/中选项，下确认。长下保留回首页（音量页先回房间；相册使用确认返回）。

首页长中进入资料编号设置，上/中选择，下保存。编号只是本地资料槽，可以重复；原SN保持，通信按硬件MAC区分。6台使用同一份固件，资料可通过小程序或蓝牙测试助手设置。房间调度自动选取在线可用设备，无需固定任意设备开机。

进入「组队」直接播放“一起加入【Aidol直播房间】”动画，完成即为对讲模式。每次回首页都退房，重进重新播放。菜单统一按「和全体队友对讲→玩游戏→返回→各位队友」排序，显示和按键共用同一列表。列表只显示当前入房且在线的名字、远中近和信号，最多5位队友与全体/游戏/返回同屏可见，右上显示实际队友数，不再隐藏分页；信号条左低右高、底边对齐，不显示头像。空房间只有玩游戏/返回，无发言目标。RSSI不代表米数或方位。近档最强者可放大，中/远同字号；离线约3秒移除。

对讲保持原半双工协议。默认播放90%；已有设备升级时用volume90_v1初始化一次，之后保存手动选择。手机连接期间暂停对讲；游戏前请断开小程序。房间列表中游戏中的队友标注忙碌，不能私讲给该队友，全体只由可收听成员播放。

两台激活后停在首页，几乎贴近并持续约2秒，双方持续选择唯一极强近邻，最强者领先至少6dB，满足1.8秒/10个新样本，且收到持续300ms至少2个新HELLO的双向意向后才弹窗；确认前先预览对方头像，双方分别短下确认后保存完整名片并自动打开详情。长下取消；保持贴近不会重复弹，拿开至近期信号低于贴近范围约0.6秒，再靠近满足约1.8秒条件可重试。不存在固定几十秒CD；真实距离阈值仍需现场标定，RSSI不是碰撞或厘米传感器。未激活、手机连接、游戏及其他页面不会抢屏。

v0.7.6 名片采用4片窗口发送和656字节乱序缓存，仍为同一HSW2偏移协议、原64×104 RGB565好友头像、MAC/会话/CRC校验，不缩小图片。一次只提交一帧，最短5ms，优先心跳，自己累计请求不会被对方持续请求饿死；35ms回退支持老版单片发送。头像确认80ms重发；相同已校验快照不重复擦写。收完并校验本地名片后先保存本机好友记录，再由双方已保存的HELLO完成握手，不再把独立尾ACK作为入库前置条件。临时好友记录写失败500ms重试；仍保留6秒无实际进展/20秒总上限、短下重试和长下返回。进度条综合双向传输和保存状态，双方真实保存前不会显示100%。日志cards_detail/cards_store/cards_session/cards_radio区分阶段、字节数、双向会话与ESP存储错误。

同一完整HELLO/14%丢包+重复+乱序模拟由v0.7.4的6744ms/621帧降为4488ms/492帧（约33%更快）；20种20%丢包/重复/乱序和12–25ms循环全部通过，另测尾ACK全丢、文字/头像不对称、持久保存暂败/永久失败及旧v0.7.4单片对端。模拟耗时不代表现场速度。实机分阶段日志确认双方握手、对方已收完头像，但本机未接受META；只读蓝牙资料确认对端为默认喵喵三行签名。原校验拒绝换行，已用完全相同签名复现单边收完/单边0%的失败。v0.7.6仅为签名允许LF换行，昵称/标题及其他控制字符限制保持；小程序、Flash资料和名片接收采用一致规则。现场修复结果另列于验证记录。

好友列表显示本机保存的头像、昵称和签名，最后一项返回；每页最多四行，长方形头像等比显示。详情有头像、昵称、静态换行的16px签名（超长时14px）、固定「示例二维码」和可见返回；签名左对齐，不滚动。二维码不含账号或链接，是不可扫描的展示图；不是好友真实二维码。好友资料是添加时的离线快照。本版把好友记录绑定双方MAC；升级会忽略旧版仅按编号保存的好友，需要重新加好友，保留本机头像/昵称/签名/相册。

相册默认同样为不可扫描的示例图片，可通过小程序上传240×320基线JPEG照片替换。任意按钮先显示返回，短下确认，上/中取消；同一次按键不会直接退出。相册与个人头像相互独立。

## 唱跳挑战

开场3秒准备：正常佩戴距离哼一个舒适低音，自动校准基准。游戏新增正常佩戴声音门槛（去直流RMS300开启、180关闭，连续两次40ms有效人声），降低弱环境声误触；对讲拾音增益保持原值。单麦克风不能区分同样响的近处多人声音，现场仍需核对正常佩戴时本人和邻座的声音差异。基准低音约32px，普通升调逐步向上，约基准1.65倍达到最高处；发声才以固定速度前进，停声100ms后停步、240ms后自然下落，可在宽木桩上无限等候换气。最高处的闪亮金币要求达到约基准1.65倍以上的音高，声音更大不能替代升调。右侧小竖条反馈高度。两只刺球采用更宽容的身体碰撞范围，接近时分别提示低音／高音通过。第一枚普通币下移，方便用低音起步拿币。六段木桩、蓝色低河面、两只旋转刺球和12枚金币组成1000像素固定关卡，没有20秒截止。

落水/撞球/撞木桩扣50分（最低0）。撞球复活在该球右侧的安全平台并更新检查点，落水/撞木桩退回最近安全落点；已取金币不会重新生成，每枚只计一次。普通金币50分、闪亮高音金币100分、通关100分，最高900分，无落台刷分。连续吃币有连击提示。终点后1.8秒彩带，再进入结算；完成时即保存，未完成退出不记本局成绩。左上为金币数量，右上为分数。

当前是原创高低音自由哼唱路线，不逐音还原歌曲、不识别歌词、不播放原曲；不会唱也能根据金币位置哼唱。参考输入轨迹已在生产C模型验证无死亡全金币900分；真人麦克风和舞台噪声下的难度需要实机测试。

开场中央大字3、2、1逐秒显示，并各有一声增强提示音（70/70/100ms）；死亡为180ms中频下降音（1200→550Hz），通关为500ms上行音阶。死亡/通关合成信号增强，保留数字余量；总音量仍默认90%。程序用现有扬声器线程异步合成16kHz PCM，不嵌入音频文件，不增加任务/队列/堆音频缓冲，沿用本机音量。每个事件只播放一次，退出游戏、连接小程序或休眠会取消音效。麦克风持续读取，但音效及最后一帧后200ms的回声期不参与判音，同时清空音高窗口与中值历史；画面、按键、游戏逻辑和房间心跳继续运行。

结算保存个人最高分；低分不覆盖，断电保留。排行榜只列当前房间在线且有有效成绩的成员，按个人历史最高分排序，同分同名次；无人完成过游戏显示空态。保存失败显示保存中并重试。成绩格式HRS6拒绝早期试做游戏的旧成绩；新游戏版本与房间会话绑定成绩包，离房/断线不残留旧成员。本版使用新HSW2通信协议，v0.7.1与v0.7.0、v0.6.x可互通，不能与v0.5.x联机。游戏、声音和灵敏度沿用已确认的v0.5.9规则。

游戏用原麦克风的16kHz PCM作整数基频检测，音高持续控制高度；无额外音乐伴奏或按键替代控制。原绘制的白鸡、草台、水波、云、金币和旗帜采用Flash中的小尺寸RGB565/A8素材，蓝色天空用8像素宽抖色条平铺，避免大图片和额外帧缓冲。UI目标25fps，实机麦克风抗噪、流畅度与舞台环境仍需验收。

## 构建与安装

```sh
. /path/to/esp-idf-v5.5.3/export.sh
idf.py build size
cmake -S tests -B build-host
cmake --build build-host -j6
ctest --test-dir build-host --output-on-failure
python3 tests/test_release.py
python3 tests/test_safe_flash.py
python3 tools/package_ble_release.py
python3 tools/verify_release.py releases/v0.7.10
```

源码包含字体、图片、原Aidol欢迎音频和来源记录。LVGL9.5.0，JPEG库1.0.2；首次依赖安装需联网。蓝牙翻页仍为独立设备，其他社区案例未加入。

用分段包安装：bootloader 0x0、partition table 0x8000、app 0x10000，**禁止全片擦除**。官网自定义固件入口直接选本版-web.bin，起始地址0x0，不勾选全片擦除。合并BIN不跨SN，但覆盖原普通NVS（0x9000～0xefff）；需要保留原普通NVS时使用分段包。

```sh
python3 tools/safe_flash.py --release releases/v0.7.10 \
  --port /dev/cu.usbmodem具体端口 --expected-mac 具体MAC --skip-backup --execute
```

工具比较SN、原NVS、演示配置/资料/好友/相册并完整回读固件；skip-backup只跳过整机备份，不跳过保护检查。v0.7.10本轮仅构建与打包，尚未写入实体设备；历史实机结果见 docs/verification.md。需要恢复新机测试时，用蓝牙测试助手选择人物并重置演示数据、激活/欢迎及最高分，原SN和原NVS保留。重置与一般保留数据升级是两个明确步骤。
