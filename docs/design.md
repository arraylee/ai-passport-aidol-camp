# 六人捉迷藏＋对讲机 demo v0.1.1

2026-10-20；用户要求直接实现最小 demo。独立工程，复用 work/hide-and-seek 的 BSP，不继承房间、抓人规则、倒计时或素材。

## 硬件依据
现有 bsp_pins.h / bsp_audio.c：ESP32-C3、8 MB、无 PSRAM、240×320 ST7789；上/下/中三个 ADC 键（0–150 / 150–447 / 447–1900 mV），ES8311 16 kHz 单声道。麦克风 no_dac_ref=true，输入增益 30 dB。以当前代码核对，未接实机验证本批次。

## 实现选择
- 同一份固件，首次选号 1–6，版本化 CRC 设置保存在独立 demo_cfg NVS 分区 0x360000/0x6000。普通 nvs 与 cardid 均不初始化、不擦除。保存失败留在设置页明确提示。demo_cfg 原内容不兼容或损坏时仅格式化该 24 KB 分区，可能覆盖旧应用在该处的资源；不擦除其他区域。
- ESP-NOW 固定信道 6、无需路由器。所有设备发送心跳，按 MAC+启动随机数绑定编号，重复编号显式报错。3 秒无消息离线。
- 1 号是唯一发言权仲裁者。所有人发送音频广播，按接收对象过滤。1 号离线时停止对讲但保留其他五台信号显示；1 号重启后新 epoch 废弃旧授权。单一演示组，不支持同场多组隔离或加密私聊。
- 请求每 120 ms 重试；授权每 120 ms 重发；授权回显最后收到的请求时间，发话者按自身请求时间在 450 ms 过期，仲裁者 700 ms 收不到请求则释放；释放重发三次。1 号启动隔离 900 ms、每次释放/撤销后隔离 650 ms，避免旧授权与新发话者重叠。每次按住最多 30 秒，忙碌不自动排队，需松手重按。音频帧必须与当前授权的 speaker / target / request / epoch / token / boot 匹配；不能拿旧包续期。
- 16 kHz/16 bit 单声道，IMA ADPCM 每 20 ms 独立压缩 320 个采样（164 字节）；头部与 CRC 后总计 200 字节，低于 ESP-NOW v1 的 250 字节。每帧独立预测器防丢包串扰；不重传过时语音。小队列与播放预缓冲，队列耗尽时补静音，过期帧丢弃。未做逐帧时钟重排，丢帧可能导致语音短暂跳过。
- 每 300 ms 心跳用于 RSSI；EMA、单次变化限幅、远中近迟滞、趋势短窗比较；音频包不改变 RSSI采样频率。无角度、米数或精确测距承诺。
- 主界面使用锁定目标视图：24 px 目标姓名、40 px 远中近、信号条与趋势，下面四名队友各有 20 px 姓名与信号条；全体页显示五人。五格条按迟滞远中近显示 1/3/5 格，离线空条。用户确定六台：喵喵、胡彦斌、王珞丹、小狮日记、手工耿、LKs。没有空间位置、角度或方位暗示。
- 上/下短按在释放时切换对象；长按上 350 ms 请求发言，释放停止，不先切人。长按下 600 ms 返回全体；中键短按切换音量页，页内短按上下调音量，长按下退出；长按中 800 ms 进入身份设置。身份页短按上下选择、中键保存、长下取消。首启必须保存身份。持有发言键时忽略其他导航；ADC 键直接交叉切换会停止发话并等待中立状态。上电持键被忽略，防误发话。
- ADC 共线不采用组合键。运行中不睡眠，避免漏收与按键唤醒限制。

## 工作顺序与验证
1. 纯 C 状态/协议/输入/编解码/设置测试，包括六节点模拟丢包、同时抢话、迟到授权、重复编号、重启、释放丢失。
2. ESP-IDF 平台、音频任务、原生大字 UI 与字体覆盖检查。
3. ESP-IDF 5.5.3 编译、size；host UBSan 测试；原生 240×320 截图与边界检查。
4. 无跨身份区的 web BIN + 分段包 + 源码包；验证实际二进制分区、写入扇区范围、哈希及 ZIP 一致。
5. 提供逐台备份/显式分段写入/身份读回工具及六台测试表。本次仅构建打包，不烧录，不提交/推送。

## 内存预算
LVGL 48 KB 池、9.6 KB 单画布，射频 RX 队列约 5 KB，PCM/ADPCM 队列合计 < 8 KB，音频与网络各约 5 KB 栈、主任务 8 KB，禁止整屏动态变换。静态 size 不能证明运行时堆余量；每 10 秒日志记录 heap/min_heap/丢包/音频错误，六台真机至少 30 分钟压力验收。
