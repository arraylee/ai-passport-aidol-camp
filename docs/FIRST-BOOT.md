# v0.7.12 首次激活后直接首页

实机 v0.7.11 在没有本地设置的新设备上，先显示待激活，激活后仍进入旧的“设备组网编号”页。页面要求六台编号不同，与当前按设备身份寻址、自动选择协调设备的联机方式不符。

修正后，在演示设置可用但缺少有效人物设置时，先保存默认人物和90%音量；欢迎、待激活之后直接显示首页。已有有效人物、头像、签名、音量和激活记录继续保留。设置写入失败仍显示可重试错误，不将失败当成功。

首页长按中键的手动入口保留，改为“人物资料”：显示人物名字，说明不同胸卡可用相同资料，避免将本地资料槽误当组网地址。

蓝牙连接期间暂停待激活页的激活操作，避免配置还在执行时实体按键改变激活记录、造成助手最终回读失败。断开后仍可正常短按下键激活。

回归用真实生产设置编码和存储函数验证首次默认、已有资料与用户音量、损坏记录、失败提交与重试；页面状态机验证蓝牙连接期间不激活、断开后恢复。v0.7.11 实机发现问题并不代表 v0.7.12 已完成实机验收，具体记录独立保存。
