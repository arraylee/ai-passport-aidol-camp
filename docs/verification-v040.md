# v0.4.0 验证记录

本版已完成源码集成、ESP-IDF构建及发布包校验；以本目录 `evidence/*-v040.log`、发布manifest及源码重建报告为最终证据。**没有写入实机**。用户明确表示稍后回来实机测试，当前不把旧版音频确认当成本版验收。

## 构建与交付结果

- ESP-IDF 5.5.3编译/size成功；应用2,167,696字节，3MiB应用分区尚余31%。静态DRAM报告202,326字节；这不是运行时可用堆。
- 19/19宿主测试、5项分区测试、5种安全刷写模拟、字库检查通过。所有新逻辑均在最终源码下验证。
- 解压交付源码到新目录、复用已锁定第三方依赖缓存、重新编译全部应用对象；bootloader、partition table、app三段与发布文件逐字节相同，见`evidence/source-rebuild-v040.json`。
- Web BIN从0x0写入、结束于0x221390，未跨SN；SHA256为`057f07df8d785f532b5155b32855b9680d1f295d49d7e32dcb70a977e6571533`。现有设备升级仍用分段包，避免覆盖原NVS。
- app从0x10000写入，SHA256为`fc6573de8f87c553c792e6c89d0b701d3664f49247a59cf369b7c36f4bbfdead`。
- 发布BIN/ZIP/源码与manifest逐文件哈希核对通过。界面图为实际固件UI在宿主LVGL渲染，非实机照片。

## 自动化覆盖

- 19项宿主测试：core/input/controls/pages、实际无线轮询计时、六台网络争用及房间版本、信号平滑、好友握手与过期、资料编辑、头像存储、UI、好友卡片交换与Flash、相册、休眠、电源恢复、实际音频初始化/停止函数的失败路径。UBSan开启。
- 六台网络模拟10分钟、20%独立控制包丢失，不产生双发言者；私人目标仅目标接收，全体给其余五台，未入房者不接收。包含1号掉线/重进和30秒发言上限。模拟时间不等于实机运行时间。
- 好友模块覆盖116个Flash写入故障点、部分写入、损坏回退、重启、owner隔离、重复/乱序/丢包和MAC/boot/session/CRC绑定。双实例经真实pack/unpack在模拟75丢包/41乱序下完成；不是实机传输速度。
- 相册测试使用真实JPEG API头文件与解码器替身，验证协议、大小、截断、会话撤销、Flash失败和旧图保护。**真实RISC-V JPEG库、手机上传及内存峰值尚待实机验证**。临时条带7680B，解码器另有内部堆；手机编辑时暂停并释放音频资源，恢复失败限频重试。
- 10分钟边界、计时回绕、busy结束重新计时、首帧闩锁、亮暗渐变、唤醒按键消费、休眠拒绝恢复均有宿主测试；并未实际等待一台设备深睡/唤醒。
- 240×320原生LVGL渲染逐标签检查字库及边界，并人工查看截图；不代表实机帧率、堆峰值或无看门狗复位。
- 分区/镜像边界测试与安全刷写模拟：仅写bootloader/partition/app，6个保护范围前后比较。未执行真实写入。

## 已知条件

- 无路由器，固定ESP-NOW信道6；1号是发言调度者，必须开机并加入房间。参与本轮的六台须统一版本。
- 用户实测“下键”在旧版日志为604mV/CENTER_HOLD，本版把逻辑下键统一到604mV，中键303mV，上键0mV；新映射须由用户实机确认。
- 本机深睡即离线，不能接收对讲；醒来回首页，需重新加入房间。GPIO0数字低电平唤醒，先使用上键，其他键待测。
- 相册默认是example.com示意码，不是用户微信二维码；小程序应上传自己的码。
- 好友以演示编号保存快照，旧版仅好友位图的记录需重新互加补齐头像，修改资料后重新互加刷新。
- 80%亮度、10分钟休眠均不构成六小时续航证明。六台真机网络、音质、按键手感、所有动画长稳、实际休眠/唤醒与六小时续航全部待测。

旧版证据仅作历史：[v0.3.3及更早记录](verification-through-v033.md)。v0.3.3用户确认双向声音及互加成功，不计入v0.4.0硬件验收。
