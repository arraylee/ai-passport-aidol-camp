# AI PASSPORT 蓝牙测试助手 v0.3.7

双击「启动AI PASSPORT助手.command」，允许 macOS 蓝牙访问。原界面改用蓝牙，不需要接 USB。

1. 胸卡先升级到配套 v0.7.0。旧固件可识别 SN，但会提示需升级，无法执行蓝牙清理。
2. 打开、唤醒需要配置的设备，断开小程序；点「扫描设备」。
3. 扫描后自动读取各台的原 SN、当前昵称和签名。再为需要换人的设备明确选择目标人物，可选择相同人物。
4. 勾选设备，点「设置并重置所选」。也可以点单台的「设置并重置」。
5. 每台显示「已完成，蓝牙回读一致，设备未重启」后即可使用。断开蓝牙后设备播放欢迎语，短按下键激活。

「设置并重置」恢复所选人物头像、昵称和签名，清空好友、成绩、激活/欢迎记录及自定义相册，音量90%。

「清空数据」保留当前人物头像、昵称、签名、编号和原 SN；清空好友、成绩、激活/欢迎记录及自定义相册，音量90%。支持单台和批量清空。

原 SN、原身份区、原普通 NVS、程序和分区表不会写入。管理期间暂时停止对讲，完成断开后恢复。不使用 esptool、串口、全片擦除或设备备份。

一次最多处理六台，同时传输两台，其他台自动等待。失败只影响对应设备，不会当作成功；唤醒、重新扫描识别后可重试。清理过程意外断电时，新固件会在下次启动继续完成已提交的清理。未完成的头像传输仍需重新执行。

首次使用需要 Mac 蓝牙权限；若拒绝，请在「系统设置→隐私与安全性→蓝牙」允许启动助手的应用，再重开助手。若设备没出现，确认开机、已唤醒、小程序已断开，再扫描。处于休眠或整机卡死的设备无法接受蓝牙配置。

运行环境：macOS、Python3.10+、Bleak2.0.0。当前电脑已配置；解压到另一台Mac时启动器会创建本地运行环境。服务仅监听127.0.0.1，网页无需云端账号。

验证边界：已完成协议/清理边界/失败分支测试、固件构建、Mac原生蓝牙实扫两台并读取旧版SN；新固件免重启换人/清空及六台批量仍需配套版本实机确认。详见固件目录 docs/BLE-CONSOLE.md。

显示规则：当前设备资料和将要设置的人物分开显示。扫描时不预选人物。自定义头像只有在设备回读的像素CRC与已有预设一致时才预览；内置喵喵头像按已核对的固件版本、当前编号和无自定义头像状态显示。其他自定义头像会明确提示暂不支持预览，昵称和签名仍正常读取。当前蓝牙接口不支持下载自定义头像内容。旧固件的蓝牙接口只能读SN时，会明确提示当前人物未读取。

发现设备：每次合并三轮、每轮7秒的扫描结果。历史设备本轮没出现时保留卡片并标记「本轮未发现」，不算在线、不允许清空或设置。配对信息失效会明确提示具体设备；请在macOS蓝牙设置中仅移除该设备的旧配对记录后重连。

第6个预设已由LKs替换为「京东3C数码」，使用京东官方JOY形象，签名为「谁敢横刀立马 唯我3C数码 战斗战斗 只做第一」。

京东3C数码头像更新为用户参考图左上角站立JOY，透明PNG；胸卡上透明部分贴合首页深色背景显示。姓名和签名保留。
